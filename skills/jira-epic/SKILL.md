# Epic

An Epic describes a large outcome, significant deliverable, or capability. Stories, Tasks, and Bugs sit beneath it. Describe the result and scope, not a list of implementation steps. Make success measurable. Mark missing facts as open questions.

## Template

```markdown
## Objective

<High-level capability or outcome>

## Problem

<What larger problem are we solving?>

## Desired Outcome

<What should be possible when this Epic is complete?>

## Scope

### In Scope

- <Capability>
- <Capability>

### Out of Scope

- <Explicit exclusion>
- <Explicit exclusion>

## Acceptance Criteria

- <Measurable outcome>
- <Measurable outcome>

## Dependencies

- <Dependency>

## References

<Designs, decision records, documentation, or related initiatives>
```
